## 核心知识校对

1. Go Mutex 正常模式中被唤醒 waiter 与新到来 goroutine 竞争；饥饿模式直接交接。源码中 1ms 是等待阈值而非计时器自动切换。饥饿模式退出还考虑是否最后一个 waiter、等待时间是否少于 1ms。
2. defer 正确规则：函数值/参数注册时求值；return 赋给结果变量后逆序执行 defer。具名与非具名结果要区分。Go 代码示例输出 `5 3 4 10`。
3. 镜像二叉树可完整用 BFS 队列或 DFS 栈实现，正确处理 nil、交换子树、避免意外共享并发修改。
4. 一致性哈希要明确稳定 Hash + 虚拟节点 + 排序 + lower_bound + 尾部回绕 + 物理节点映射 + 去重选副本 + 成员变更迁移，不能只说“顺时针找节点”。
5. DODO PMM Base 库存不足时边际价 `P(B)=i(1-k+k(B0/B)^2)`；当 i=100、B0=100、B=80、k=0.1，边际价 105.625；从 B=100 卖到 B=80 的 20 Base 的示意累计 Quote 2050，平均成交价 102.5（不含费）。
6. RFQ 是报价/成交协议，PMM 是定价和库存管理算法。PMM 亦可视作广义 AMM 内的一种实现，比较时应注明 CPMM 指恒定乘积 AMM。

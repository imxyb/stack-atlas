# Stack Atlas 内容导入与排版规范

本规范用于后续在 ChatGPT 中继续维护题库，防止从聊天复制的纯文本被直接当作 Markdown 列表。

## 导入规则

1. 不要对粘贴源文本逐行统一加 `- `。必须先识别自然语言段落、章节标题、字段集合、代码和执行流程。
2. 每道深度问答优先按 **核心回答 → 原理 / 流程 → 关键设计或对比 → 高级追问** 排版。
3. 自然语言段落用普通段落，不要一个句子一个圆点或一行一个段落。
4. 多阶段执行流程使用 `text` fenced code block、Mermaid 或交互图，不能用单独的“↓”生成列表项。网站会把带“↓”的 text 代码块渲染为流程卡片。
5. 多维度方案对比优先使用 Markdown 表格；示例 SQL 和 Solidity 必须使用带语言标签的代码块。
6. 数据库字段 / Token Metadata 集合应按语义聚合，不要为每个字段创建一条列表。
7. 从不同题目复制时，必须移除“某章标题”“下一道题开头”等混入答案的噪声。
8. 技术内容保持来源框架；必要的事实修正要单独注明，不能悄然改变用户项目叙述。
9. 编辑已有题目尽量保留 ID，避免个人收藏和复习状态断裂。
10. 发布前运行静态验证：JSON 可解析、题目 ID 唯一、全部 inline 脚本通过 JS 语法检查、交互图映射有效。

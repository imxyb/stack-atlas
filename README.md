# Stack Atlas

高级后端与 Web3 工程师面试知识库。

**线上地址**：https://imxyb.github.io/stack-atlas/

## 内容
- Go、MySQL、Redis、Kafka、分布式系统
- Solidity、以太坊 EVM、MPT 三棵树、Gas、交易执行、链上后端
- 可交互图解、题库检索、收藏与本地复习进度

## 维护方式
直接在 ChatGPT 对话中提出修改需求，由已连接的 GitHub 工具更新本仓库。推送到 `main` 后，GitHub Actions 会尝试发布 GitHub Pages。

**注意**：本站目前为静态网站。访客在网页内的收藏、笔记和个人编辑保存在自己的浏览器中，不会自动同步至 GitHub 或其他设备。

## 自动部署
请在本仓库 **Settings → Pages → Build and deployment** 将 **Source** 设为 **GitHub Actions**。
发布工作流位于 `.github/workflows/deploy.yml`。
部署记录可在 **Actions** 标签页查看。
